# 🚗 Gestion des Véhicules

Application web full stack permettant de gérer, visualiser et analyser des véhicules.

---

## 🛠 Technologies utilisées

- **Backend** : Node.js / Express
- **Base de données** : MongoDB
- **Frontend** : HTML / CSS / JavaScript
- **Machine Learning** : Python (régression, KNN, arbre de décision)

---


## ⚙️ Fonctionnalités

- 📋 Affichage dynamique des véhicules depuis MongoDB
- ➕ Ajout de nouveaux véhicules
- ✏️ Modification des véhicules
- ❌ Suppression des véhicules
- 📊 Visualisation des données (graphes)
- 🤖 Prédiction du prix avec des algorithmes

---
## 🚀 Lancer le projet

### Backend
```bash
